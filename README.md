## The entry

> The senator who spent three hearings demanding AI explain itself in plain English just asked his intern to print the PDF so he could fax it back.

One satirical sentence (145 characters) roasting lawmakers who would regulate AI but cannot convert a file to PDF. The setup grants the senator authority — three hearings demanding AI explain itself — then undercuts it with the file he cannot convert, and the punch lands on the last words: print the PDF to fax it back.

## How it works

`main.py` (Python 3, standard library only) writes the single sentence deterministically to `/output/entry.txt`. Two runs produce byte-identical output.
